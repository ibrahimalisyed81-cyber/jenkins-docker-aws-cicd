# Automated CI/CD Pipeline Using Jenkins, Docker and AWS EC2

## Project Overview
This project aims to build an automated CI/CD pipeline
using GitHub, Jenkins, Docker and AWS EC2.

## Project Objective
To automate the process of building, testing and deploying
a web application using DevOps tools.

## Tools and Technologies
- Git and GitHub
- Linux
- Jenkins
- Docker
- AWS EC2

## Planned Workflow
1. Push application code to GitHub.
2. Jenkins detects code changes.
3. Jenkins executes the pipeline.
4. Docker builds the application image.
5. Deploy the application to AWS EC2.
